# Accessibility

Marine Tools aims to make practical maritime calculators and technical helpers usable across desktop, tablet, and mobile devices.

Accessibility is treated as an ongoing product requirement rather than a claim of formal conformance.

## Current approach

The project aims to provide:

- responsive layouts for desktop, tablet, and mobile screens;
- readable text and strong visual contrast;
- visible focus states for interactive controls;
- keyboard-accessible buttons, links, forms, and navigation where practical;
- meaningful labels for form controls;
- alternative text or appropriate decorative treatment for images;
- interfaces that do not rely on colour alone to communicate important states;
- clear validation and error messages;
- layouts that remain understandable when content wraps or screen width is reduced.

Marine Tools uses a dark maritime interface and includes a Bridge Dark display option. Both are intended to preserve legibility and distinction between normal, caution, warning, and alert states.

## Known limitations

Marine Tools has not been independently audited or certified for compliance with WCAG or another accessibility standard.

Some experimental live-data, map, chart, third-party, or browser-provided components may have accessibility limitations outside the direct control of the project.

Because Marine Tools is under active development, regressions may occasionally occur.

## Reporting an accessibility barrier

If something prevents you from using Marine Tools effectively, please report it to:

**contact@marinetools.app**

A useful report includes:

- the page or tool affected;
- what you were trying to do;
- what happened instead;
- browser and device;
- assistive technology, if relevant;
- a screenshot where useful.

Please do not include confidential vessel, company, or personal information unless it is necessary to explain the problem.

Accessibility reports can also be submitted as a GitHub issue when the problem is suitable for public discussion.

## Scope and safety

Accessibility improvements do not change the safety boundary of Marine Tools. The service is a planning and calculation aid only and does not replace approved equipment, official publications, vessel procedures, manufacturer documentation, or professional judgement.
