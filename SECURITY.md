# Security Policy

Marine Tools takes security and privacy issues seriously.

Marine Tools is a proprietary maritime helper-tool project operated by Walterfang Design. The publicly deployed service is available at https://marinetools.app.

## Reporting a security issue

Please **do not open a public GitHub issue** for suspected security vulnerabilities.

Report security concerns privately by email:

**contact@marinetools.app**

Use a clear subject such as:

`Security report — Marine Tools`

Please include, where relevant:

- a description of the issue;
- the affected page, endpoint, or feature;
- steps to reproduce the issue;
- the potential impact;
- browser, device, or environment information;
- screenshots or a minimal proof of concept that does not expose sensitive data.

Do not include passwords, API keys, access tokens, confidential vessel information, personal data, or other third-party secrets in the report.

## Scope

Security reports may cover issues affecting the official Marine Tools service, including:

- `marinetools.app`;
- `api.marinetools.app`;
- source code maintained in the official Marine Tools repository;
- authentication or access controls used by Marine Tools;
- privacy or data-handling behaviour implemented by Marine Tools.

Third-party services and infrastructure remain subject to their own security programmes and terms.

## Responsible testing

Please avoid testing that could:

- disrupt service availability;
- create excessive traffic or denial-of-service conditions;
- access, alter, or delete data belonging to another person or organisation;
- involve social engineering, phishing, or impersonation;
- expose credentials or confidential operational information;
- interfere with third-party systems.

Use the minimum testing necessary to demonstrate the issue.

## Supported version

Security fixes are applied to the current Marine Tools codebase and deployed service. Older local copies, cached versions, forks, mirrors, or unauthorised deployments are not supported.

## Response

Reports will be reviewed as availability allows. Marine Tools does not currently operate a formal bug-bounty programme and cannot guarantee a specific response or resolution time.

Where appropriate, reporters may be asked for additional information to reproduce or understand an issue.

## Maritime safety

A calculation discrepancy, incorrect assumption, stale external data, or usability concern may be important without being a security vulnerability. These can be reported through the normal Marine Tools suggestion or contact channels.

Marine Tools remains a planning and calculation aid only. Users must verify inputs, units, assumptions, source age, and results against approved systems, official sources, vessel-specific documentation, and applicable procedures.
