# Marine Tools — LinkedIn demo pack

Use the personal profile first. The tone should be practical and product-led rather than promotional.

## Demo 1 — Fuel & Bunkering
**Format:** 15–25 second screen recording or 3-image carousel.

**Opening hook**
A lot of maritime calculations are simple — but we still end up doing the same ones again and again.

**Post copy**
One of the reasons I built Marine Tools was to make common onboard calculations quicker to access.

Fuel & Bunkering brings several everyday workflows together in one place: ROB, consumption, endurance, density, tank transfer and bunkering-related calculations.

The goal is not to replace procedures or approved systems. It is simply to make the routine calculations easier to work with.

Marine Tools is free to use:
https://marinetools.app/?utm_source=linkedin&utm_medium=organic_social&utm_campaign=demo_fuel

I would be interested to hear which fuel calculation you find yourself repeating most often onboard.

**Demo sequence**
1. Open Fuel & Bunkering.
2. Enter a simple ROB + daily consumption example.
3. Show the calculated endurance/result.
4. End on the Marine Tools home screen.

## Demo 3 — Vessel Profile
**Format:** 20–30 second video.

**Opening hook**
A calculator is less useful if you have to type the same vessel data every time.

**Post copy**
Vessel Profile is one of the parts of Marine Tools that ties the individual tools together.

You can save vessel, machinery, tank and energy-carrier data locally in the browser and reuse those values across supported tools.

That means less repeated input and a more consistent starting point for calculations.

Marine Tools:
https://marinetools.app/?utm_source=linkedin&utm_medium=organic_social&utm_campaign=demo_vessel_profile

The data stays in the browser unless a feature clearly says otherwise.

**Demo sequence**
1. Open Vessel Profile.
2. Show vessel speed / draft / fuel data.
3. Switch to a supported calculation.
4. Show the saved values being reused.

## Demo 4 — Weather + Voyage Estimate
**Format:** 3–4 image carousel or 20 second video.

**Opening hook**
Sometimes you do not need a full passage-planning system. You just need a quick estimate.

**Post copy**
Marine Tools combines practical weather information with quick voyage estimates for early-stage planning.

Choose locations, vessel speed and relevant vessel data to get an approximate distance, sea time and fuel estimate.

It is intentionally an estimate — not a navigation or passage-planning system.

Try Marine Tools:
https://marinetools.app/?utm_source=linkedin&utm_medium=organic_social&utm_campaign=demo_voyage

Where do quick voyage estimates save you the most time — onboard or ashore?

**Demo sequence**
1. Open Weather briefly.
2. Show a point forecast.
3. Open Voyage Estimate.
4. Select two locations and speed.
5. Show distance + sea-time result.
