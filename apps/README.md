# Marine Tools app prototypes

The app foundation reuses the existing public web calculators. Capacitor 8.5.3
packages Android (including Samsung phones) and iOS. Tauri 2 packages Windows
and macOS. The staged web package also includes an installable PWA manifest.

```sh
npm ci
npm run test:app
npm run app:serve
npm run app:android:sync
npm run app:ios:sync
npm run app:desktop:build
```

Android requires Java 21 and Android SDK 36; iOS requires macOS and Xcode.
Desktop builds require Rust and the platform's native build tools. Native
projects and icons are generated from the checked-in configuration. Node 22+
is used in CI. `Native app prototypes` builds Android debug APK, iOS Simulator
app, unsigned Windows NSIS installer and macOS DMG on the feature branch.
These are development artifacts, with no app-store submission or signing setup.
An iOS Simulator artifact cannot be installed on an iPhone.

`app-dist` is generated by an explicit public web-file staging step. Education,
source scans, worker code and credentials are excluded. The protected Education
workspace remains an online link. This first prototype disables production
AIS/weather API access and analytics; local public calculators remain usable.
PWA caching applies only to the staged public package and is disabled on
Cloudflare Pages preview hosts. Existing protected-preview service-worker
rules are retained. Test offline functionality on localhost or HTTPS.

Next device milestones: verify calculator UI and file export on actual phones
and desktop installers, add native file/share adapters where browser downloads
are insufficient, decide authenticated Education delivery, then configure
release signing, developer accounts and store listings. No native sharing,
Education offline distribution, live-data integration or store release is
claimed by this foundation.
