# R134a teaching property table

`refrigerant-r134a-20261030.js` is generated from CoolProp 7.2.0 HEOS R134a. No CoolProp executable is shipped in the browser. The generated states use a single property reference convention.

Generator: `scripts/generate-refrigerant-reference-20261030.py`. Direct state/cycle reference cases are frozen separately under `tests/fixtures/`. The runtime interpolator is bounded; it never extrapolates beyond the table.

References: [R134a](https://coolprop.org/fluid_properties/fluids/R134a.html), [CoolProp source](https://github.com/CoolProp/CoolProp).
