Learning points

  • Inside the dome: wet steam with vapour quality 0 ≤ x ≤ 1.
  • At x = 0: saturated liquid. At x = 1: saturated vapour.
  • At fixed pressure: h = hf + x(hg − hf), and s = sf + x(sg − sf).
  • Superheated region: use measured pressure and temperature; vapour quality is not defined.
  • Domain limit: saturation above 160 bar(a) and the critical point are not plotted; Region 3 is not implemented.

See IAPWS-IF97 for the authoritative industrial water/steam formulation. IF97 regional property calls are calculated locally using the Neutrium implementation, with no tabular fallback when the solver is unavailable. This is not a complete Region 1–5 solver.
