# Marine Tools

**Practical tools for seafarers.**

Marine Tools is an independent, free collection of calculation, planning and technical helper tools for maritime use. It is designed and maintained by one person with a deliberately focused scope: make common maritime calculations and planning tasks easier to access, understand and verify.

## Tools

Marine Tools includes:

- Route Intelligence with live AIS and route forecast context
- Route risk context and user-defined operational limits
- CPA/TCPA context for relevant AIS targets
- Navigation, bearing, distance and coordinate tools
- Great-circle vs rhumb-line comparison
- True/apparent wind conversion
- Passage speed/time/fuel scenario comparison
- Weather context and weather-window calculations
- Fuel, endurance, density, blending and tank calculations
- Dynamic UKC, squat and anchor swing-radius helpers
- Fresh Water Allowance / Dock Water Allowance
- Engineering and hydraulic calculations
- Electrical, three-phase, battery and voltage-drop tools
- Vessel Profile for reusable planning values
- Unit conversions and quick technical utilities

## Safety

Marine Tools is a **planning and calculation aid**.

It is not:

- ECDIS or approved navigation equipment
- a certified decision-support system
- a PMS or maintenance-management system
- an electronic logbook
- a checklist or SMS system
- a replacement for vessel procedures, official publications or professional judgement

Users are responsible for verifying inputs, assumptions, units and results against approved systems and vessel-specific documentation.

## Privacy

Marine Tools follows a local-first approach.

Vessel Profile values, route waypoints and application settings are stored in the user's browser. Marine Tools does not use entered operational data for advertising, behavioural profiling, sale to third parties, AI-model training or unrelated employment, disciplinary, enforcement or commercial assessment.

Live-data tools send only the route or position context needed to return the requested result. Internet requests may pass through hosting, maritime-data, map and network providers, which can have their own technical logging and data-processing practices.

Survey and suggestion submissions are separate from locally stored operational data.

## Data sources

Live-data features may use external maritime and mapping sources. Source availability, age and limitations should always be considered when using live information.

## Feedback

Marine Tools is shaped by practical feedback from seafarers. The website includes separate **Survey** and **Suggestions** sections for feature ideas, improvements and bug reports.

## Interface

Marine Tools uses two dark display modes:

- **Dark Maritime** — the standard interface.
- **Bridge Dark** — a lower-luminance amber/red-biased mode intended to reduce blue/cyan glare in dark environments.

Individual calculation cards can be starred and collected under **My Tools** on the home page. Results can be copied directly, and selected calculators include visible formula and assumption notes for easier verification.
